# 赛事管理员操作手册

| 项目 | 说明 |
|---|---|
| 适用对象 | 校级管理员、协会负责人、学院负责人；普通会员可对照「会员能做什么」一节 |
| 适用版本 | 四协会（匹克球 / 乒乓 / 羽球 / 网球）、校级活动（石榴籽杯 / 运动会 / 跨校邀请赛）、协会级个人赛、实时计分台 |
| 核心原则 | 先抽签、后开赛；比分由选手录、对手确认；确认即最终结算，已生效不可撤销；名次提交即结束 |
| 一句话 | 校级活动管学院与学校，协会赛事管个人，两本账互不相干 |

---

## 一、先读这一页：角色、入口与红线

### 1.1 四个角色，权限逐级放大

系统里没有「超级账号」，权限由三层合成：平台账号的全局角色、学校的校级角色、协会里的协会角色。日常你只需要知道自己属于哪一档。

| 操作 | 会员 | 学院负责人 | 协会负责人 | 校级管理员 |
|---|---|---|---|---|
| 报名 / 取消报名 / 查看成绩 | 可 | 可 | 可 | 可 |
| 录分（本人参赛的场次） | 可 | 可 | 可 | 可 |
| 确认比分（对手方） | 可 | 可 | 可 | 可 |
| 驳回待确认的比分 | 可（有确认资格时） | 可 | 可 | 可 |
| 代会员签到 | 不可 | 可（本院） | 可 | 可 |
| 代录比分（非本人参赛） | 不可 | 可（本院有人上场） | 可（本协会） | 可（任意） |
| 指派 / 改派裁判 | 不可 | 不可 | 可 | 可 |
| 发布 / 抽签 / 开赛 / 结束赛事 | 不可 | 不可 | 可（本协会） | 可 |
| 发布石榴籽杯、审名单、抽签、开赛、结束 | 不可 | 不可 | 可（本项目） | 可 |
| 发起运动会、编排、发布成绩、结束 | 不可 | 不可 | 不可 | 可 |
| 学院报名、院内审核、派学院部长 | 不可 | 可（本院） | 可 | 可 |
| 发起跨校邀请赛、锁定名单、抽签、确认名次 | 不可 | 不可 | 可 | 可 |
| 任免协会负责人 | 不可 | 不可 | 不可 | 可（唯一入口） |
| 开始新赛季（清赛事积分） | 不可 | 不可 | 可 | 可 |

> **红线一**：已经「已生效」的比赛没有撤销按钮。录错了必须在「待确认」阶段由对手驳回；一旦确认，等级分已按结算链写死。这条是为了让账本可信——录入者能抹掉记录，分数就没有公信力。

> **红线二**：只能管自己范围内的东西。学院负责人管不了别院名单，协会负责人管不了别的协会，校级管理员跨协会都能管但改不了历史结算。

### 1.2 三个入口，别找错地方

底部三个页签：**首页 / 协会 / 我的**。

```
首页 ─── 公告、近期赛事、协会快捷入口
协会 ─── 四个协会宫格 → 协会工作台
      ├─ 石榴籽杯（学院团体赛）
      └─ 运动会
我的 ─── 我的成绩 / 会员审核 / 公告管理 / 学校身份 / 跨校邀请赛
```

协会工作台顶部还有四个页签：**协会空间 · 排行榜 · 比赛 · 赛事**。协会内的一切操作都从这里进。

### 1.3 五类活动，五本账

| 栏目 | 参赛单位 | 成绩去向 | 谁管 |
|---|---|---|---|
| 协会级个人赛 | 会员个人 | 计个人等级分 + 赛事积分 | 协会负责人 / 校级管理员 |
| 石榴籽杯（学院赛） | 学院 | 单打小场计个人等级分；名次只记学院，不计个人积分 | 协会负责人（本项目）/ 校级管理员 |
| 运动会 | 学院 + 个人 | 学院总分与个人荣誉，**不进 Elo、不进赛季积分** | 校级管理员（学院部长协作） |
| 跨校邀请赛 | 会员个人（跨校） | 单独留档，**不计个人等级分** | 发起方协会负责人 / 校级管理员 |
| 团队赛事（篮球） | 球队 | 只记球队名次与技术统计，**不进个人 Elo、不进赛季积分** | 协会负责人 |

### 1.4 最容易搞错的六件事

1. **先抽签，后开赛。** 抽签入口只在「报名中」出现；点了「开始赛事」就再也不能抽签或重抽。
2. **抽签即冻结名单。** 之后没有报名与取消报名的入口，要换人只能重抽。
3. **没录比分不能确认。** 会提示「这场比赛还没有比分，请先录入成绩」。
4. **大场未排齐不能开始。** 石榴籽杯里双方学院都提交排阵后，「开始大场」才生效。
5. **名次一提交，赛事立即结束且不可再改。**
6. **学院名次不改变任何人的等级分与积分。** 两套体系互不干扰。

## 二、协会工作台：日常都在这里

### 2.1 协会空间

协会空间是协会自己的园地，四块内容：

| 区块 | 能做什么 | 谁能管 |
|---|---|---|
| 分组 | 建长期小组（新手组、校队组），拉人进出，归档或删除 | 协会负责人 |
| 通知 | 发内部通知、修改、撤回；只在本校本协会可见 | 协会负责人 |
| 训练 | 发布训练、定时间地点与人数、报名审核、签到确认 | 协会负责人 |
| 成员 | 看本协会成员与小组归属 | 全体会员可看，负责人可调 |

训练签到有两种入口：会员自助签到（需在开放时段内）和管理员在签到页逐人确认。签到状态可以撤销，撤销后该次训练不计训练积分。

> 训练积分与赛事积分是两套独立聚合，互不冲抵。赛季更新时两者都从零开始，但**等级分不动**。

### 2.2 排行榜

- **单打榜**：按当前等级分排，男女分开展示，底层同一个池。
- **进步榜**：按「当前分 − 入池起点分」排，起点分只在首次入池时写一次，不随赛季刷新。
- **赛事积分榜**：只统计本赛季内结束的赛事，赛季更新后归零。

### 2.3 比赛：所有比分的总入口

「比赛」页签列出本协会的全部比赛流水，包括个人赛、石榴籽杯小场，以及日常约球。这里是改判与补录的集散地。

| 想做 | 条件 | 谁能做 |
|---|---|---|
| 录分 | 比赛「待确认」 | 参赛者本人 / 学院负责人（本院有人上场）/ 协会负责人 / 管理员；指派裁判后仅裁判与管理员 |
| 确认 | 已录比分、状态「待确认」 | 对手方（非录入方）；指派裁判后仅裁判与管理员；管理员不受限 |
| 驳回 | 状态「待确认」 | 有确认资格的人，需填理由 |
| 弃权 | 状态「待确认」、本人参赛 | 参赛者本人；管理员可替任一方 |
| 指派 / 改派 / 取消裁判 | 状态「待确认」 | 协会负责人 / 管理员 |

**驳回与弃权的区别**：驳回是「这份成绩不作数，请重录」，比分清空、比赛仍待打；弃权是「这一场不打了」，对手直接晋级、比分留空、不计等级分。

> 指派裁判后，录分与确认都收窄为「裁判本人或管理员」。裁判临时来不了，管理员取消裁判即回到普通口径。

### 2.4 赛事

协会级个人赛的列表与发布入口。点右上角「发布」进入表单，点「全部赛事」看历史。详见第三节。

> **团队运动（篮球）不同**：它的工作台只有「协会空间 / 组队 / 赛事」三个页签，没有排行榜与个人比赛——篮球不进个人等级分。「赛事」页签进去是**团队赛事**（球队报名、抽签、录总分），详见第七节。

## 三、协会级个人赛：发布 → 名次

### 3.1 发布

协会工作台 → 赛事 →「发布」。

| 字段 | 必填 | 说明 |
|---|---|---|
| 赛事名称 | 是 | 2–30 字 |
| 项目 | 是 | 单打 / 双打。双打不计等级分与积分 |
| 组别 | 是 | 单打：不限 / 男单 / 女单；双打：不限 / 男双 / 女双 / 混双 |
| 赛制 | 是 | 六选一，见 3.2 |
| 小组数、出线人数 | 小组类必填 | 2 / 4 / 8 组；每组出线 1–4 人 |
| 赛事等级 | 是 | 一级 / 二级 / 三级，同时决定 K 值与名次分倍数 |
| 三四名赛 | 单败类必填 | 并列季军 / 打三四名 |
| 种子来源 | 是 | 手工指定 / 按等级分 / 按赛季积分（双打无赛季积分） |
| 种子数量 | 是 | 2 / 4 / 8 |
| 日期、时间 | 是 | 不能早于今天 |
| 场地、名额、说明 | 否 | 名额不填视为不限 |

等级与 K 值、名次分的关系：

| 等级 | 每场 K | 名次分倍数 | 冠军名次分 |
|---|---|---|---|
| 一级 | 32 | ×4 | 80 |
| 二级 | 24 | ×2 | 40 |
| 三级 | 16 | ×1 | 20 |

名次档位：1→20、2→14、3→10、4→7、5–8→4，未进八强 0；所有参赛者另加 2 分参与分。日常约球的 K 值也是 16，但不产生赛事积分。

### 3.2 六种赛制怎么选

| 赛制 | 建议人数 | 特点 | 名次来源 |
|---|---|---|---|
| 单败淘汰 | 4 人以上 | 输一场即出局，最快 | 手动录入 |
| 循环赛 | 3–8 人 | 人人交手，最公平 | 自动按战绩 |
| 小组赛+淘汰 | 8 人以上 | 先分组循环，出线后交叉单败 | 自动预填 |
| 循环赛+淘汰 | 5 人以上 | 单组循环取前几名进单败 | 自动预填 |
| 双败淘汰 | 4 人以上 | 输两场才出局，设胜者组/败者组/总决赛 | 自动按轮次 |
| 小组赛+双败 | 8 人以上 | 小组出线后进双败 | 自动按轮次 |

双败类可开「总决赛重赛」：开启后胜者组冠军先记 1:0，首场若输则加赛一场。单败类可开「5–8 名排位」：八强战负者加赛两轮，分出名次。

### 3.3 报名与抽签

会员在赛事详情页自助报名、取消报名，本版本没有报名审核。管理员要盯三件事：人数够不够、名额满没满、名单要不要调。

抽签流程：

1. 确认状态是「报名中」。
2. 点「开始抽签」（重抽为「重新抽签」）。
3. 种子来源为「手工指定」时，先按顺序点选种子：第 1 个点中的是 1 号种子，再点一次取消，点「清空」重来。双打每 2 人合成一组种子。
4. 确认「抽签后名单锁定，报名随即截止」。
5. 系统生成签表或分组，并生成首轮比赛（待确认）。

重抽的前提是**没有任何一场比赛确认生效**；重抽会作废现有签表与其中未确认的比赛，但不重新开放报名。

### 3.4 开赛与签到

- 未抽签就点「开始赛事」不会生效，会提示「请先抽签，再开始赛事」。
- 开赛后状态变为「进行中」，报名截止。
- 签到由学院负责人或管理员代签，会员不能自助签到。签到不改变签表。

### 3.5 录分：手填与实时计分台

两个入口效果相同：赛事详情 → 签表 → 某场比赛「录分」；或「比赛」页 → 该场「录分」。

**手填比分**：对阵与赛制由抽签锁定，逐局/逐盘填写，胜方由系统判定。适合照边裁报分补录。

**实时计分台**：在录入页顶部点「实时计分」进入横屏计分台，逐球判定，可撤销上一球，打完点「结束比赛」定稿。

- 计分权与录分权同源；开台后这场比赛只能一个人推进。
- 定稿只把打完的局/盘写成正式比分，比赛仍是「待确认」，确认权照旧在裁判 / 对手手上。
- 网球在计分台上是三层显示：盘分、本盘局分、本局分（15/30/40/AD）；6:6 自动进入抢七，抢七分数按原始数字显示。

**网球的赛制选项**（四协会里只有网球有）：

| 选项 | 取值 | 默认 |
|---|---|---|
| 盘制 | 一盘决胜 / 三盘两胜 | 一盘决胜 |
| 每盘局数 | 6 局标准盘 / 4 局短盘 | 6 局 |
| 无占先 | 开 / 关 | 关（需净胜 2 分） |

比赛记录里存的是**盘比分**（如 6:4、7:6），抢七小分单独存一份，展示成 `7:6(5)`。

### 3.6 确认、驳回、弃权

- **确认**：默认由对手方确认；管理员可确认任意一场。演示环境下放宽为「任一参与者」，以页面提示为准。
- **驳回**：待确认阶段把成绩打回，需填理由（例：第二局比分录反了）。
- **弃权**：本人放弃，对手晋级，不计等级分，比分清空并标注「弃权」。

确认后比赛变为「已生效」，等级分当场结算并写入结算链，同时触发下一轮自动生成。

### 3.7 裁判指派

管理员 / 协会负责人可以在「待确认」阶段为单场比赛指派裁判，也可以改派或取消。指派后：

- 录分与确认都只有裁判本人和管理员能做；
- 参赛者看到的提示是「本场由 XXX 裁判执法」；
- 已生效的比赛不能再改派。

### 3.8 晋级与加赛

- 单败：胜者自动进下一轮；半决赛后按设置生成三四名赛或并列季军。
- 5–8 名排位：八强战全部结束后生成排位赛。
- 小组类：各组循环结束排出组内名次，全部打完且达到出线人数后生成淘汰赛。
- 双败：胜者留胜者组、负者落败者组，败者组再输即淘汰，最后进总决赛。

系统只补生成缺失的场次，绝不覆盖已有比赛，可以放心一场一场确认。

### 3.9 名次与结束

状态为「进行中」时，赛事详情 →「录入名次并结束」。

| 赛制 | 名次来源 |
|---|---|
| 循环赛 / 双败 | 自动 |
| 小组类 | 自动预填，可微调 |
| 单败淘汰 | 手动逐人录入 |

校验规则：每人一个名次且 ≥1；至少给一位参赛者录名次；只能给本赛事报名者录名次；并列季军不应出现第 4 名；打三四名时第 3、4 名必须成对。

提交后赛事「已结束」，名次冻结，等级分与积分按名次重算。**结束后不能再改**。

### 3.10 个人赛答疑

| 现象 | 原因与处理 |
|---|---|
| 会员报不上名 | 是否已抽签（名单锁定）、名额是否满、账号是否在册、是否已离校 |
| 看不到「开始抽签」 | 赛事不在「报名中」，或当前账号无管理权 |
| 提示参赛人数不足 | 单打 <2 人；双打 <4 人或人数为奇数；双败 <4 人 |
| 点确认提示「还没有比分」 | 先录分 |
| 点确认提示「你无权确认」 | 确认人须为对手方（管理员不受限） |
| 看不到下一轮比赛 | 上一轮还有比赛未确认 |
| 比分录错且已生效 | 已无撤销入口；只能在结算前驳回，或联系开发者在后台处理 |
| 看不到「弃权」 | 只在本人参赛的「待确认」场次出现 |

## 四、石榴籽杯：学院团体赛

石榴籽杯是校级活动，但**每个球类项目各自就是一屆杯赛**，项目来自协会注册表。它的底层仍是学院赛：以学院为单位组队，两院之间打一场「大场」，大场里按小项序列逐项打小场。

### 4.1 入口与结构

协会页签 →「石榴籽杯」→ 顶部切换项目（匹克球 / 乒乓 / 羽球 / 网球）→ 下方是该项目的杯赛列表。

| 结构 | 说明 |
|---|---|
| 杯赛（学院赛） | 一个项目可以一年办多次，按发起时间归档，不设「第几届」 |
| 大场 | 两院之间的一轮对抗，含若干小项 |
| 小场 | 大场里的一个具体项目（男单、女双……），落在「比赛」流水里 |

### 4.2 发布杯赛

项目负责人或校级管理员点「发起」。字段：

| 字段 | 必填 | 说明 |
|---|---|---|
| 赛事名称 | 是 | 2–30 字 |
| 小项序列 | 是 | 逐项添加，每项从男单 / 女单 / 男双 / 女双 / 混双里选；行号即出场顺序；1–20 项，同名可重复 |
| 允许兼项 | 开关 | 默认开；关闭后同一人在一场大场里只能打一项 |
| 最少 / 最多人数 | 否 | 每院名单人数区间，默认 4–20 |
| 胜负算法 | 是 | 打满比净胜（默认）/ 先到 N 场胜 |
| 净胜口径 | 打满时 | 小场胜场差（默认）/ 累计局分净胜 |
| 日期、时间、场地、说明 | 时间必填 | — |

「先到 N 场胜」的 N = 小项数 ÷ 2 向下取整再加一。例如 7 项，先赢 4 项即胜。

### 4.3 名单与审核

1. 学院负责人在杯赛详情提交本院名单：只能勾本院在册会员，人数须落在区间内，同一人勾两次只算一次。
2. 提交后为「待审核」，管理员逐份「通过」或「退回」，退回必须写理由。
3. 名单里出现非本院或账号不可用的会员，系统直接拒收。
4. 抽签只认「已通过」的名单；抽签后名单锁定。

本版本没有独立替补名单：名单里本场没上场的人就是替补，可直接换上。

### 4.4 抽签

- 至少 2 个已通过名单的学院才能抽签。
- 学院没有等级分，种子只能手工指定：按顺序点选学院，第 1 个是 1 号种子。
- 抽签后赛事转「待开赛」，可停在这里核对对阵再开始。
- 重抽前提：没有比赛确认生效。

### 4.5 两级开赛：排阵 → 大场

1. 「开始赛事」：赛事转「进行中」，按签表生成首轮大场（每个大场初始「待排阵」）。
2. 双方学院各自排阵：每个小项点人，单打 1 人、双打 2 人。再次进入排阵页会带出上次提交的那份。
3. 双方都提交后，大场变「待开赛」。
4. 管理员点「开始大场」，生成各小场比赛记录，大场转「进行中」。

> 大场未排齐（哪怕只差一方）时，「开始大场」不会生效。这是有意为之：从源头避免「开赛后再记弃权」。大场一旦开始，排阵即锁定。

### 4.6 小场录分、裁判与弃权

小场的录分、确认、驳回与个人赛完全一致，走「比赛」页或大场详情。

- **裁判**：可按大场指派裁判，指派后下发给该大场的每个小场；也可对单个小场改派。
- **弃权**：学院赛的小项弃权由管理员记录（不是参赛者自己点），需指定哪一方弃权；该小项记对手获胜、比分留空、不计等级分，但照常推动大场。
- **计分**：单打小场按一级赛事口径计个人等级分（K=32）；双打小场与弃权场次不计。

### 4.7 大场胜负怎么算

| 算法 | 判定 | 何时结束 |
|---|---|---|
| 先到 N 场胜 | 一方先赢够 N 个小项 | 赢够即结束，剩余小项不必再打 |
| 打满比净胜 | 全部小项打完，按发布时选的口径比净胜 | 所有小项分出胜负后 |

「打满比净胜」先用发布时选的口径比，打平再比另一口径；两套都平则大场判为**未决**，停在「进行中」，不会硬判赢家——需管理员核实处理。

### 4.8 轮次推进与名次

一轮里所有大场都结束后，系统自动推出下一轮，直到只剩一个学院。轮空者直接进下一轮。有未决大场时不会推进。

全部打完后，管理员「录入名次并结束」：按学院填名次，至少且只有一位冠军，每所学院只能记一次，只能给已通过名单的学院记名次。

### 4.9 网球项目专项

网球是全站唯一的三级计分项目，进杯赛时有两处固定口径：

- **小场赛制固定为 4 局短盘 + 无占先**（一盘约 20 分钟），不受个人赛的默认配置影响；
- 大场里的小项照常按「男单 / 女单 / 男双 / 女双 / 混双」排，但每场都是短盘。

比分展示为 `6:4 7:6(5)`；大场汇总的「累计局分净胜」口径对网球等于「累计赢下的局数」。

### 4.10 学院赛答疑

| 现象 | 原因与处理 |
|---|---|
| 看不到「发起」入口 | 不是本项目负责人或校级管理员 |
| 负责人交不了名单 | 只在「报名中」可提交；抽签后锁定 |
| 提示「名单里有不属于本学院的会员」 | 只能勾本院在册会员 |
| 抽签提示学院不足 | 已通过审核的学院不足 2 个 |
| 某学院没进签表 | 该学院名单还没通过审核 |
| 点「开始大场」没反应 | 双方排阵未齐 |
| 排阵改不了 | 大场已开始或已结束 |
| 大场迟迟不结束 | 两套净胜口径都平，判为未决 |
| 下一轮没出现 | 本轮还有大场未结束或未决 |

## 五、运动会

运动会是学校级栏目，**不属于任何协会**，所以入口在「协会」页的校级活动档，权限也只认校级管理员与学院部长。

### 5.1 一届运动会的一生

```
筹备中（草稿） → 报名中 → 赛程已发布 → 进行中 → 已结束 → 已归档
```

| 阶段 | 谁在干活 | 关键动作 |
|---|---|---|
| 筹备中 | 校级管理员 | 填基本信息、勾项目、设每项配额 |
| 报名中 | 学院部长 / 管理员 | 学院提交报名、院内审核、管理员终审、迟到报名窗口 |
| 赛程已发布 | 管理员 | 定赛制、分组/抽签、派裁判、发布赛程 |
| 进行中 | 裁判 + 管理员 | 裁判逐场录分提交，管理员按场次发布成绩 |
| 已结束 | 管理员 | 总榜定稿、荣誉落定 |

### 5.2 发起与配项

「运动会」→「发起运动会」是两段向导：

1. **基本信息**：名称、年份/届次、日期范围、地点、主办单位、说明。填完先建草稿。
2. **勾项目**：从项目目录里勾选，并为每项设「每院报名人数上限」。**勾选即保存**——勾上就写库，取消就删除，不需要记着点保存。

草稿期可以随意改；一旦发布报名，规则就不能再动（会影响已提交的报名）。

### 5.3 学院报名与审核

1. 管理员「发布报名」，运动会转「报名中」。
2. 学院部长（由管理员任免）在「学院报名」页提交本院各项目名单，逐项检查人数是否超配额。
3. 院内先审一遍，再交管理员终审；被退回的条目要写理由。
4. 报名截止后如需补报，管理员可开「迟到报名窗口」，窗口内仍可提交。

### 5.4 编排：派裁判、定赛制、分组

报名截止后进入「赛程编排」页，顺序就是页面从上到下：

1. **派裁判**：先选项目与场次（可跨项目多选），再选裁判（可多人）。整个上午的径赛常是同一批裁判，所以放在最上面。
2. **定赛制**：径赛选轮次（直接决赛 / 预赛+决赛）、每组人数（跑道数）、晋级人数；田赛与群体项目按规则生成签表或循环。
3. **分组 / 抽签**：径赛按跑道数自动均分，多枪决赛就是分几枪；胜负项目生成签表或循环赛。

编排完成点「发布赛程」，运动会转「赛程已发布」。

### 5.5 录分与成绩发布

- **裁判**：「我的任务」→ 点开场次 → 逐条录入成绩 → 提交。提交后该场次锁定，管理员可退回重录。
- **管理员**：「录分与成绩发布」→ 先选场次（默认决赛）→ 预览汇总（均值、缺分提示）→ 发布正式结果。

> 成绩必须**按场次**发布：有预赛的项目分多组，每组分别发布。发布是事务操作，学院总分与个人荣誉同时累加，不会出现「榜上有分、荣誉没有」。

### 5.6 总榜、荣誉与结束

- **学院总榜**：按学院累计总分排序，名次由服务端按竞赛排名（1、2、2、4）算好，页面不重排。
- **我的荣誉**：个人在本届的获奖记录，随成绩发布同步生成。
- **结束**：管理员点「结束运动会」，之后成绩与总榜冻结。

运动会成绩**不进个人 Elo，也不进赛季积分**——它是独立的第三本账。

### 5.7 运动会答疑

| 现象 | 原因与处理 |
|---|---|
| 看不到「发起运动会」 | 不是校级管理员 |
| 项目勾了却没保存 | 勾选即保存；若列表没更新，刷新页面 |
| 学院报不了名 | 运动会不在「报名中」，或已过截止且未开迟到窗口 |
| 提交提示超配额 | 该项目每院人数超过发布时设的上限 |
| 裁判看不到任务 | 未被指派到该场次，或场次尚未发布赛程 |
| 管理员发布成绩提示有缺分 | 该场次还有人没录，先补齐或退回重录 |
| 总榜不动 | 成绩还没发布；预览不等于发布 |

## 六、跨校邀请赛

跨校邀请赛用于和外校交流，**不计个人等级分**，成绩单独留在邀请赛的账上。

### 6.1 发起与邀请

「我的」→「跨校邀请赛」→ 发起：填名称、赛制（与校内赛同一套六种）、时间、地点，选择要邀请的学校。对方学校在自己的页面「接受」或「婉拒」，也可以撤回邀请。

### 6.2 报名、锁定与抽签

1. 被接受的学校组织本校会员报名。
2. 发起方「锁定名单」：锁定后不能再报名或取消。
3. 「抽签」生成对阵；可指派裁判。
4. 到场比赛，录分 → 确认。

### 6.3 名次与收尾

全部比赛确认后，发起方「确认名次」，赛事转「名次已确认」。已确认的比分不可撤销——跨校赛涉及两个学校，事后改分会破坏双方共有的记录。

## 七、团队赛事（篮球）

篮球与四个球拍运动是两套账：球拍运动是**个人**报名、个人等级分；篮球是**球队**报名、只记球队名次与技术统计，**不进个人 Elo**。所以它有自己的入口、自己的赛程与自己的名次算法。

### 7.1 入口与结构

工作台（篮球）→「赛事」→「进入团队赛事」。列表一行一届，右下角「＋ 建赛」只有协会负责人及以上看得到。

一届赛事的一生：

```
建赛（报名中） → 锁定名单 → 抽签（赛程已发布） → 录分 → 发布 → 进行中 → 结算名次（已结束）
```

### 7.2 建赛：赛制与规则当场固化

| 表单项 | 选项 | 说明 |
|---|---|---|
| 赛事名称 | 2–30 字 | 同协会不可重名 |
| 赛制 | **单败淘汰 / 循环赛** | 首版只支持这两种 |
| 规则 | **FIBA 四节 4×10 / 校园 2×20** | 决定节数、节长、犯规口径、加时长度 |

两条硬规矩：

1. **规则在创建时固化**。开赛后再改规则，前面打过的比赛就不可比了——要改只能新建赛事。
2. **小组赛+淘汰、三人制暂未开放**。接口会直接拒绝，而不是悄悄按单败淘汰处理（那会让人以为小组赛已经能用）。

### 7.3 组队与报名

1. 学生申请建队 → 协会负责人审核（见「组队」页签）。
2. **队长**在赛事详情里为本队报名；协会负责人审核通过。
3. 报名下限是**满 5 人**（场上 5 人齐即可比赛，不强制替补），上限 12 人。
4. 全部审核完，点「锁定名单」。锁定后：不能再报名、不能换人；名单里每个人的姓名当场拍成快照，之后球队改名、退队都不回写这一场。

> 为什么要锁定：历史成绩按快照认人。不锁的话，赛后再往队里塞人，名次就成了可以事后编辑的东西。

### 7.4 抽签

状态到「名单已锁定」后，点「抽签并生成赛程」。

- **单败淘汰**：按标准种子排位，强手分散到不同半区；队数不是 2 的幂时自动补轮空，轮空不产生比赛、直接晋级。
- **循环赛**：一次排完全部轮次（圆桌轮转法），人人碰一遍。
- 可以把某些队设为**种子**（按顺序传入），其余队伍洗牌。
- **重抽**：只要还没有任何一场录过分，就可以重抽（签抽错了、有队退赛）。一旦有比分，抽签被拒绝——重抽等于把打过的比赛从赛程里删掉。

### 7.5 录分与发布

| 步骤 | 谁能做 | 结果 |
|---|---|---|
| 录分 | 协会负责人 / 管理员 / 参赛两队的队长 | 比赛转「待审核」 |
| 发布 | 协会负责人及以上 | 转「已发布」，进入积分表与名次 |
| 驳回 | 协会负责人及以上 | 退回「未开赛」，**比分清空**，等重录 |

比分规则：

- 填两队**总得分**（0–299 的整数），不是逐节比分。
- 淘汰赛**不允许平局**：打平会直接拒绝并提示打加时。循环赛只有规则快照里开了「允许平局」才接受。
- 打了加时把开关打开，记录上会留痕。
- 0:0 不是有效比分。

> 录完不等于发布。两队队长都可能录错，发布是协会负责人核对记分牌的那一步；只有发布之后，这场才进积分表。

### 7.6 名次

**淘汰赛**：决赛打完点「结算名次」。冠军 = 决赛胜者，亚军 = 决赛负者；有季军赛时以季军赛定第 3、4 名，没有则按「被淘汰的轮次」倒排（越晚被淘汰名次越好）。每轮打完后点「排下一轮」生成下一轮对阵——上一轮还有比赛没发布时，这一步会被拒绝。

**循环赛**：全部打完点「结算名次」，按积分表排名。排序口径依次是：

1. 胜场
2. 相互战绩（只算同胜场那几支队彼此之间的比赛）
3. 净胜分（得分 − 失分）
4. 总得分
5. 球队编号（兜底，保证两台机器算出同一个名次）

> 名次只在**所有比赛都发布之后**才允许结算。带着未发布的比赛结算，第二天补录一场，名次就变了。

### 7.7 团队赛事答疑

| 现象 | 原因与处理 |
|---|---|
| 建赛时选了小组赛，提示不支持 | 首版只做单败淘汰与循环赛 |
| 报不了名，提示「只有队长可以为本队报名」 | 让队长提交，或由协会负责人代为报名 |
| 报名提示「至少需要 5 人」 | 球队在队人数不足，先审核入队申请 |
| 「抽签」按钮不出现 | 赛事还停在「报名中」，先锁定名单 |
| 抽签提示「已经有比赛录了分」 | 已开打，不能重抽；要改只能新建赛事 |
| 录分提示「篮球不允许平局」 | 淘汰赛必须分出胜负，打加时后重录 |
| 「排下一轮」提示还有 N 场未发布 | 先把上一轮的比分全部核对发布 |
| 「结算名次」提示还有 N 场未发布 | 同上；结算要求全部定局 |
| 队员看得到赛程但点不了录分 | 录分只给协会负责人与两队队长，按钮由服务端下发 |
