# 学校维度 S2：身份申请与审核

日期：2026-10-13

S0/S1 基础已提交：`bcc49eb`。按用户最新指示，本阶段不部署云环境，继续本地开发。本文记录 S2 的第一个业务切片，完整学校页面、校内计分与赛事接入仍待继续。

## 已接通的链路

绑定学校的客户端 → 云函数协议 2 分流 → 服务端以微信 OpenID 构造学校上下文 → 身份处理器 → 数据库事务 → 审计记录。

四个 action：

| 接口 | 参数 | 访问要求 |
| --- | --- | --- |
| applySchoolMembership | collegeId、studentId | 有效平台账号，仅申请自己；有其他主要学校身份时拒绝普通申请 |
| getMySchoolMembership | 无 | 仅返回本人在目标学校的身份，不接受前端指定他人 userId |
| getSchoolApplications | 无 | 本校有效校管理员或平台管理员；只返回该校待审核记录 |
| reviewSchoolMembership | userId、decision、revision、reason | 本校审核权，禁止自审，驳回必填理由 |

请求必须带 `protocolVersion: 2`、`schoolId`、`association`。携带学校字段但不带协议版本的请求拒绝；旧 submitMatch 等尚未迁移的 action 不进入学校路由。无学校信息的原单校请求继续走旧入口。

客户端 `miniprogram/services/school-cloud.js`：

```js
const { forSchoolIdentity } = require('./school-cloud');
const api = forSchoolIdentity({ schoolId: 'buaa', association: 'pkb' });
await api.applySchoolMembership({ collegeId: 'c01', studentId: 'TEST100' });
// 审核账号使用相同学校客户端：先读取申请，再传入对应 revision。
await api.reviewSchoolMembership({ userId, decision: 'approve', revision });
```

这是云接口适配器，云环境未配置时会明确报错，不会把请求伪装成成功。现阶段业务验证使用双校内存夹具，不自动切换现有演示页面的数据源。

## 一致性与权限

- 审核事务内重读审核人账号、学校状态、学校身份、校管理员授权、申请版本与申请人账号。请求开始后撤销管理员权限，后续提交会被拒绝。
- 学校申请具有 revision。同一待审核内容重试不增加版本；修改申请或重新申请会改变版本，管理员不能审核旧页面上的内容。
- 同校学号占用保存在新增 `student_id_claims` 集合。主键为学校与学号组合的 SHA-256 摘要，记录只存学校、占用者与时间，不在主键或审计日志中直接写学号。
- 学号比较采用去掉首尾空白后的原字符串，保留前导零、区分大小写，不擅自套用某校格式。
- 占用、主要学校指针、学校身份、审核审计在同一事务中提交。任一步数据库故障都会回滚。
- 不同学校可以使用相同学号。不同学校并发审批同一用户时，用户文档上的 primarySchoolId 为共同写入点，事务重试后重新检查，避免形成两个主要学校身份。
- 对 S1 种子或已有学校身份，审批前检查有效/离校/停用身份上的既有学号；新审批统一创建占用文档。正式迁移时还应为所有保留身份回填占用，迁移期间必须停写。
- 审计使用确定的文档 ID，在云事务中按 doc(id).set 写入。失败不留下已通过身份，重复提交已处理申请也不生成第二次审核。
- 转校、离校后重新入学及停用恢复暂不开放普通申请路径，需要后续专门流程处理，不通过覆盖记录绕过限制。

批准时增加用户的 schoolIdentityVersion。当前学校身份读取直接查询新表，不复用旧计分快照；S2 的计分接入必须把此版本或等效学校版本纳入新缓存失效规则，不能认为旧排行榜已跟随更新。

- 页面固定本次请求的学校与体验身份，旧响应不能覆盖新选择；提交中禁止切换和重复提交；失败恢复按钮并保留表单。

### 本地体验步骤

1. 微信开发者工具中编译本项目，进入“我的 → 学校身份”。
2. 体验身份保持“模拟申请人”，选择北京航空航天大学。
3. 选择任一模拟学院，填写未占用的学号（例如 NEW003），提交后显示待审核。
4. 切换体验身份为“北航校管理员”，查看申请，可通过或填写理由驳回。
5. 切回“模拟申请人”，查看审核结果；若已通过，再浏览民大不能重新申请成为民大学生。

这套学校演示身份与原演示账号 u01 相互独立，切换不会修改原页面的登录态、协会选择或比赛数据。关闭小程序后学校演示数据重置。页面显示“模拟数据”，不代表真实校方、真实学生或认证结果。
