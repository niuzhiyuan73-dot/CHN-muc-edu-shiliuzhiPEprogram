# 篮球单人实时计分台

日期：2026-10-20

## 范围与入口

用户已确定按「同时只有一位计分员」使用，取消原 P4 的多人占用、交接和协作设计。
篮球赛事详情 → 赛程 → 某场「实时计分 / 继续计分」，打开横屏计分台。
横屏主台左侧为球队加分，右侧仅当前场上球员。全台使用固定布局；球员录入、换人、累计技术统计各自切换界面，多人名单和分节记录使用分页。
有录分权限的队长、协会管理者和被指派的记录员可使用；未授权成员只看比分。

## 已实现

- 两队各有 +1、+2、+3 大按钮，支持快速连点；总分与本节分立即预览。
- 点击按顺序逐笔自动保存，显示「保存中 / 已保存 / 未同步」。
- 撤销上一操作，支持回退加分或换节；撤销后重发旧请求不会把已撤分数加回来。
- 根据赛事规则显示 2 节或 4 节；结束常规时间后平分可进入加时，也可连续加时。
- 分节表、总分与加时标记；可仅给球队加分，也可选球员加分并同步球队总分。
- 支持「只补个人得分」，以及篮板、助攻、抢断、盖帽、失误、犯规的增减；球队分与球员合计可不一致，差额仅提示。
- 球员统计与比分在同一事务保存，撤销一起回退；复用现有统计草稿与审核发布，不另建一份榜单。
- 球员来自报名与出场快照，保留已填统计；未记录显示「—」，已记 0 显示 0，按节模式支持加时统计。
- 服务端保存实时态，重进恢复；未确认操作按「运行模式 + 学校 + 协会 + 账号 + 比赛」留在本机。
- 断网或回执丢失后可重试相同操作编号；版本冲突提示重新载入，并由用户确认是否放弃未同步操作。
- 其他账号在赛事详情每 2 秒批量刷新比分与节次，标注「非最终结果」；页面隐藏暂停、回前台补拉、退出取消。
- 结束比赛把总分、分节分与加时标记原子提交为待审核；仍由原有发布流程生效，不提前进入榜单。
- 计分过程中普通手填总分接口拒绝覆盖，结束后计分台只读。

## 落点

| 文件 | 职责 |
|---|---|
| `miniprogram/pages/team-live-score/` | 单人计分台、串行保存、重试与本机未同步操作恢复 |
| `miniprogram/utils/basketball-live.js` | 加分 / 撤销 / 换节的纯逻辑与客户端摘要 |
| `miniprogram/services/team-event-service.js` | `startTeamLiveScore`、`updateTeamLiveScore`、`getTeamLiveScores` |
| `miniprogram/pages/team-event-detail/` | 单场入口、实时比分与节次展示 |
| `miniprogram/services/live-watch.js` | 复用统一轮询，增加版本变化识别与请求未完成时不重叠请求 |

实时态嵌入 `team_matches.liveScore`，不增加集合。每次操作在事务内重读身份与权限，
先核操作编号幂等，再核实时版本，避免重复请求或旧设备覆盖。正式比赛版本仍随写入更新。
云端 / mock / 客户端 action 与写动作清单均已登记，新增纯模块进入云端镜像清单。

计分与统计操作流水用于撤销与请求去重，不记录投篮命中 / 出手明细，也不自动关联得分与助攻判定。
不增加比赛倒计时、24 秒计时、犯规自动判罚、多记录员协作；进行中在同一计分台录统计，赛后可在原表格核对补录。
本轮不含部署与真机验收，跨设备同步仅在接入同一云数据源时成立，本地模拟各设备不共享内存。

## 球员统计、弹层与横屏追加

## 无滚动计分与场上换人追加

- 主台保留球队总分与 +1/+2/+3，右侧只显示当前队的场上球员（最多 5 人），可切换队伍。
- 点球员进入单次操作界面，选得分、篮板、助攻、抢断、盖帽、失误或犯规；确认保存成功后自动返回。等待期间禁止重复录入，失败留在原界面重试。
- 累计球员表、球队与个人分差、分节比分全部移入「技术统计」界面，主台不渲染累计表。球员表与分节表每页最多 5 行，替补也每页最多 5 人，无滚动区域。
- 以前只有本场出场名单，没有当前场上状态。现在以 `liveScore.onCourt.A/B` 单独保存场上阵容；默认出场名单前 5 人，少于 5 人显示缺员提示。未设置本场出场名单时沿用已锁定报名快照。
- 「换人」选择场上一人和替补一人，事务保存后自动返回；一进一出，换下者统计保留，允许再次换回。换人也可撤销，重进不重置阵容，丢回执重试不重复执行。
- 服务端拒绝给场下球员记分/统计，并验证换上者属于本队本场出场名单，拒绝跨队、重复上场或非场上者下场。计分期间固定本场出场名单，避免从赛程修改名单绕过换人。
- 旧实时比赛首次恢复时补齐场上五人状态，不改动旧统计与比分。

本轮专项测试：`tests/team-live.test.js` 与 `tests/team-live-pages.test.js` 共 26 条全部通过，覆盖换人权限与非法请求、重进、撤销、单次记录自动返回、失败重试和分页。
布局已通过 WXML 结构检查；实际微信横屏显示效果尚未做真机验收。

本轮最终回归：`npm test` 140 个文件、2662 条用例全部通过，0 失败、0 超时；78 个云端共享文件同步检查、WXML 结构与事件绑定检查、`git diff --check` 通过。


## 球员操作覆盖右侧追加

根据用户反馈，球员单次操作改为右侧固定覆盖面板：左侧球队比分保持显示，右侧名单被操作项替换，不追加到名单下方。页面根容器改为固定占满可用窗口，并清除全局最小高度，操作面板采用紧凑的三列两行布局。

面板内提供「取消返回」，未选统计项时仅关闭界面，不发送计分请求；选择得分或统计后仍在保存成功时自动返回，保存期间避免重复操作，失败保留原笔重试。打开面板期间左侧加分暂停，关闭后恢复。

验证：计分台页面、实时计分服务、赛事页面三组测试共 66 条通过；WXML 结构、右侧面板父子关系、事件绑定、无滚动容器与 `git diff --check` 检查通过。未做实际微信视觉验收。
