## 二、两处值得记下来的设计

### 1. 可重入是硬约束，不是优化

逐轮推进走「只补不覆盖」：同一批比赛会被**反复重算**（`buildPlannedDrafts` 每次确认都跑一遍）。分配一旦依赖读库顺序，用户刷新一次页面场号就跳一次。

因此池内排序必须是**全序**：阶段 → 组 → 轮次 → 签位 → `_id`。最后一级 `_id` 兜底**不能用 `localeCompare`**——`'x_10'` 与 `'x_2'` 的先后会随运行时语言环境（ICU 之类）变化，同一份数据在不同机器上排出不同场号。代码里用的是裸 `<` / `>`。

### 2. 池键是「同一轮次」的可执行定义

需求原文只有「同一轮次」四个字，而这四个字在三种赛制下含义不同：

| 场景 | 池键 | 为什么 |
|---|---|---|
| 同轮的决赛与季军赛 | 共 `ko\|{round}` | 两者通常同时开打，分开会让它们同时拿到 1 号场 |
| 双败胜者组 R1 与败者组 R1 | 分池 | 两个区的 `round` 各自从 1 计数，合池会把不相干的两批算成一批 |
| 小组赛 A 组 R2 与 B 组 R2 | 共 `group\|{round}` | 各组同轮次通常同时开打 |

## 三、验证：不止「测试全绿」

新增的 40 条测试**做了变异验证**，确认它们真的在测东西：

| 变异 | 预期变红的用例 | 实测 |
|---|---|---|
| `planCourts` 去掉池内排序 | 两条「与输入顺序无关」 | ✅ 2 条变红 |
| `poolKeyOf` 不再区分胜者组 / 败者组 | 两条分池用例 | ✅ 2 条变红 |
| `buildInitialMatches` / `buildPlannedDrafts` 不调 `withCourts` | 个人赛抽签与晋级 | ✅ 8 条变红 |
| `buildTiesForRound` 不调 `applyTieCourts` | 学院赛大场三条 | ✅ 3 条变红 |
| `withCourts` 不回填 `courtNo` | 种子四条 | ✅ 4 条变红 |

端到端里最关键的一条断言是 `assertCourtsMatchPlan`：**落库的场号必须等于把同一批比赛放回纯函数重算的结果**。纯函数测试钉住「重算稳定」，这条钉住「写进去的就是重算的那个值」——两根钉子合起来，可重入才真立得住。

> 变异验证过程中发现过一条**假通过**的用例：小场继承大场场号那条，原本只断言「小场 = 大场」。分配整个失效时两边都是 `0`，断言照样成立。补了一句「大场自己必须有 ≥ 1 的场号」之后才真正有效。

## 四、模拟种子也排上了场号

功能做完后切到默认模拟数据源，界面上什么都看不到——种子里七场赛事都没有 `courtCount`，对局也没有 `courtNo`，赛事详情页的「场地分配」表是空的。演示与人工验收等于没有样本，所以种子也得跟着排：

| 位置 | 改动 |
|---|---|
| `services/seed.js` 的 `eventPlan` | 六场已结束赛事各带 `courtCount`，`matches.push(...withCourts(eventMatches, plan.courtCount))` |
| `services/seed.js` 的进行中赛事 | `courtCount: 4`；八进四 4 场占满 1~4 号场，半决赛 2 场回到 1、2 号场 |
| `services/college-demo.js` | 学院赛演示数据 `courtCount: 4` |

**场地数故意取了不同的值**：给 4 块场地时，8 人签表第 1 轮 4 场正好一人一块；给 2 块（第 5、12 周那两场女子单打）就得排到第二批。两种情形都要有样本，否则分批那条分支在界面上永远看不到——`seed.test.js` 里专门有一条断言「种子里确实存在场地不够的赛事」。

场号一律由 `withCourts` 现算，**没有一处手写**。手写的场号一旦与 `planCourts` 分叉，「场地分配」表就会与签表里的场号打架，而这种不一致光看数据是看不出来的。`seed.test.js` 于是把每场赛事的对局**逆序**丢回纯函数重算一遍比对：既钉住「种子里写的就是算法算的」，又顺手守住可重入。

## 五、明确没做的事

- **不能改场地数**（Q10）：项目没有赛事编辑接口，填错只能重发赛事。若要补，必须同时处理 `bumpSeason`——改的是已生成比赛的场号，读路径走 dataset 缓存，漏了这一步界面会继续显示旧场号。
- **不排具体时间**：`wave` 只是序号，不是时刻。
- **不做跨赛事场地占用**：场地池是赛事私有的，不同赛事各自从 1 号场开始。
- **不做手动改派场号**：一期全自动。
- **`location` 自由文本保持原样**，与场号并存展示，不互相替代。
