# B6 赛事小组限制与转校收尾 验收记录

日期：2026-10-16。项目收尾顺序第 6 批（B6）。接手代码基线：`本轮统一提交`（B5 完成）。

## 本批完成

按指南 §8 先盘点、再补缺：

- **盘点**：训练（P4）早已接入小组受众限制（`association-audience.js` 纯规则 +
  事务内组员关系复核）；个人赛事与学院赛在 S2 都没有——这是本批补的缺口。
  普通比赛按既定规则**不加**小组限制（赛后录分，不新建报名流程）。
- **个人赛事（B6-a，提交 `本轮统一提交`）**：发布校验 `buildAudience`（与训练同一把
  尺子，非法拒绝、旧赛事按「不限」兼容）；报名在事务内按 `associationGroupMembers`
  复核资格（命中任一选中组才可报）；详情下发 `audienceMode/audienceGroupIds`，
  `signupNote` / `canSignUp` 与写入端一致；幂等指纹纳入小组字段。G05 口径：
  报名后退组保留该报名，取消后重报失败。
- **学院赛（B6-b，本批）**：发布同样校验并落库小组限制，DTO（列表 / 详情）下发
  `audienceMode/audienceGroupIds`；`submitCollegeEntry` 在事务内逐位复核名单成员的
  小组资格——**仅一人不符合即整份提交失败**（G08），学院负责人本人入组不能替代
  选手资格。
