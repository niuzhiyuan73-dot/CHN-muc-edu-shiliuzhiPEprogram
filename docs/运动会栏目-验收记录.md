## 5. B9 整体验收发现并修复的缺陷

整体验收（演示种子 + 通读）抓到一个**真实功能缺口**和一个**返回值缺陷**，均已修复并有测试看守：

1. **`sportsMeetColleges` 从来没有任何服务写入**（B2 建模时预留，B5–B8 漏接）。后果：总榜只显示原始学院编号（`c01`）而不是学院名；列表页按学院筛选永远筛不出东西；D82 要求的「零分学院上榜」不成立。修复：`submitMeetInterest` / `submitMeetCollegeEntry` 在报名事务内落下学院范围行（名称取当届快照）；`getMeetStandings` 合并参与范围（未得分显示 0）；`published` 改看正式发布记录而非榜上行数。守护：`tests/meet-seed.test.js`「学院总榜」与「mock 装载」两条。
2. **`configureMeetEvent` 返回的 `event.eventKey` 是 `undefined`**：摘要由本地 `doc` 生成，而 `_id` 只在仓储里。页面此前不消费该字段所以没暴露；演示种子第一个撞上。修复：`eventSummary({ ...doc, _id: key })`。
3. （种子自身）排期下标误用计划数组下标，会把「决赛第 3 场」另建出来——已在种子内改为按轮次内序号计数，并留注释说明。
