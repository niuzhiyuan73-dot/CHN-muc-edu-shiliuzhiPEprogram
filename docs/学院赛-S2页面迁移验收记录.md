# 学院赛 S2 页面迁移验收记录

日期：2026-10-15。范围：本地回归收口、流程验证、文档与提交；不包含后续业务迁移或部署。

## 改动与结果

七页（名单提交、名单审核、详情、发布、排阵、小场录分、名次）统一读取
`school-college-view.js`，通过 `association-space` 写入学校与协会范围内的数据。
两个列表入口的学院赛分支与置顶同步迁移，个人赛事列表分支保留旧栈。

页面测试使用独立的 S2 夹具及真实演示身份，保留原有流程、权限与错误提示断言。
测试辅助模块只转换字段和调用参数，不复制生产判权、不向旧 mock 写数据。

回归发现并修复：

- S2 编号含 `%`，直接拼 URL 会在跳转时改变编号。学院赛导航统一编码编号，
  闭环测试解析实际跳转 URL 后打开详情，防止直接传参掩盖问题。
- 同状态学院赛排序恢复开赛时间升序，置顶优先；规则放入共享纯模块。
- 全部学院赛按分页读齐，超过单次 50 条限制不会静默遗漏。
- 详情读端保留小项、人数、赛制配置；无读取权限时页面显示真实拒绝原因。
- 置顶在事务内重读身份和赛事，将主记录与审计一起提交；失败整体回滚。
