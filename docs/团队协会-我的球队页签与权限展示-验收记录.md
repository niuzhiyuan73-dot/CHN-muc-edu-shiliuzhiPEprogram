# 团队协会：我的球队页签、累计统计和权限展示

日期：2026-10-20

本批按用户要求，在足球 F2/F3 提交 `5177272` 之后单独实施、单独提交。

## 入口调整

足球和篮球工作台改为“协会空间 / 组队 / 我的球队 / 赛事”。“我的球队”是直接加载内容的独立页签，包含当前及历史球队、参赛经历、报名成员荣誉、跨赛事累计和每届统计，不再是一张跳转入口卡。

“我的”界面移除旧球队入口。保留旧独立成绩页供历史直达链接使用，与新页签共用成绩模板和展示模块；旧导航方法改指向协会的 `myTeams` 页签。球拍协会工作台不增加该页签。

页签首次进入时取数，返回详情、再次切入或下拉刷新时更新。请求绑定学校和协会；过期响应不覆盖新结果，身份失效时清除旧成绩。

## 篮球累计

接通篮球已有的已发布统计聚合，并展示全部七项累计、场均及逐项记录场数：得分、篮板、助攻、抢断、盖帽、失误、犯规。每届统计可分别查看，工作副本和待审核新数据不进入累计。

新增个人出场覆盖字段，区分球队已发布场次、已记录单场名单的场次和本人具名出场场次。首屏不再以球队参赛总数代替个人出场；没有名单时不推定出场或缺席。旧 `totals.games` 保留为球队战绩兼容字段，新视图使用 `appearanceGames`。

足球同样展示全部基础指标及覆盖范围；未知值仍为“—”，零仍为零。仅按该指标有记录的场次计算场均。

## 图标

足球改用 144×144 透明 PNG 足球图标，沿用项目现有白色线条图标生成器，中央五边形和球面拼接线在协会主题底色上显示。注册表的 `logoIcon`、协会选择页和工作台同源；文字“足”保留为小尺寸文字标识及兜底字段。

## 权限展示

- 小组列表由后端下发 `canReadRoster`，非组员且无管理权时不显示“查看名单”。
- 普通组员不显示“移出成员”；对应处理器也阻止无权调用。离组后已展开的名册收起展示。
- 新建小组、通知、训练及编辑表单均随权限隐藏，避免角色变化后残留表单。
- 赛事后端区分录分、名单维护、排期权限。普通队长不因可维护本队名单就获得录分或排期权；已发布足球比赛不展示赛前名单、排期编辑。
- 整轮顺延仅在仍有已排时间且未录分场次时显示。
- 普通会员查看已发布足球赛后报告时展示只读成绩、名单和统计文本，不显示禁用的输入框、选择器或开关；录入人和管理员保留相应表单及审核动作。
