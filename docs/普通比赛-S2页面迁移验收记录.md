# 普通比赛 S2 页面迁移验收记录

日期：2026-10-16。项目收尾顺序第 2 批。

## 已完成

- 比赛面板与普通录分页改接协会空间 S2，身份、成员、比赛记录、实时比分和写操作使用绑定范围的客户端。
- 新增 `getSchoolMatchEntryContext`：返回调用者、可录入能力、有效成员、赛季起点、本人交手次数。没有本协会有效身份时不下发内部名单。
- 新增 `school-match-view.js` 复用既有展示构建器；录分、确认、撤销、弃权、裁判指派入口以服务端能力为准。
- 普通录入使用稳定请求编号，重复提交不新增记录；签表补录使用原比赛编号，返回页面时刷新已录比分。
- 比赛列表在本人及状态筛选后截断，补充总数、待确认数和更多标记。
- 实时比分轮询改读 S2；切换范围时停止旧订阅，旧刷新不能覆盖新结果，隐藏及卸载时停止轮询。
- 异常读取清空旧台账；写入异常释放提交状态。跨页比赛编号进行 URL 编码。
- 修复普通比赛提交上限未使用赛季边界的问题，与交手次数提示统一采用本范围赛季重置时间。
